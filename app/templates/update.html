Neue Version installieren

OrbitHub prueft nur, ob eine neuere Version auf GitHub verfuegbar ist – installiert wird dabei nichts automatisch. Fuehre die folgenden Schritte selbst auf dem Raspberry Pi aus (direkt am Geraet oder per SSH), um auf den neuesten Stand zu aktualisieren.

STATUS

Pruefe aktuelle Version...

ANLEITUNG
  1. Mit dem Raspberry Pi verbinden. Direkt am Geraet ein Terminal oeffnen, oder von einem anderen Rechner per SSH verbinden: ssh BENUTZERNAME@IP-ADRESSE-DES-PI
  2. In das OrbitHub-Verzeichnis wechseln. cd ~/orbithub
  3. Neuesten Stand von GitHub laden. git pull
  4. OrbitHub neu bauen und starten. docker compose up -d --build
  5. Optional: alte Docker-Images aufraeumen. docker image prune Bei der Rueckfrage mit y bestaetigen.
  6. Ergebnis pruefen. Diese Seite danach im Browser neu laden – das Versionslabel unten links in der Seitenleiste zeigt dann die neue Version.

Es findet dabei kein automatischer Zugriff auf den Raspberry Pi statt – alle Schritte fuehrst du selbst im Terminal aus.
