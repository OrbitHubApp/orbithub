Neue Version installieren

OrbitHub prüft nur, ob eine neuere Version auf GitHub verfügbar ist – installiert wird dabei nichts automatisch. Führe die folgenden Schritte selbst auf dem Raspberry Pi aus (direkt am Gerät oder per SSH), um auf den neuesten Stand zu aktualisieren.

STATUS

Prüfe aktuelle Version...

ANLEITUNG
  1. Mit dem Raspberry Pi verbinden. Direkt am Gerät ein Terminal öffnen, oder von einem anderen Rechner per SSH verbinden: ssh BENUTZERNAME@IP-ADRESSE-DES-PI
  2. In das OrbitHub-Verzeichnis wechseln. cd ~/orbithub
  3. Neuesten Stand von GitHub laden. git pull
  4. OrbitHub neu bauen und starten. docker compose up -d --build
  5. Optional: alte Docker-Images aufräumen. docker image prune Bei der Rückfrage mit y bestätigen.
  6. Ergebnis prüfen. Diese Seite danach im Browser neu laden – das Versionslabel unten links in der Seitenleiste zeigt dann die neue Version.

Es findet dabei kein automatischer Zugriff auf den Raspberry Pi statt – alle Schritte führst du selbst im Terminal aus.
